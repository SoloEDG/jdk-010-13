# LUMEN 光学实验室

安装依赖：`npm install`

本地启动：`npm run dev`

类型检查：`npm run typecheck`，生产构建：`npm run build`。

Docker 启动：`docker compose up --build`，访问 http://localhost:18110 。

## 光谱扩展（version 2 文档）

- 每个光源带有 `spectrum`：`mono`（单条谱线）、`lines`（离散谱线）或
  `continuous`（连续波段）。每段都有相对权重，波段能量 = 光源功率 × 权重 / 总权重，
  所以增删波段只重新分配功率，不会增加总功率。
- 旧版 version 1 文档（每光源一种波长）在加载时升级为**一条**谱线，波长与功率
  原样保留，光路与能量与原实验一致。
- 棱镜色散模型在 550 nm 处等于设定折射率 `index`，向两端加强，使同一棱镜把不同
  波段分开落到接收屏不同位置。
- 接收屏分析可按波段筛选；叠加柱状图显示各波段贡献的能量。

### 采样与误差

`preview`（拖动器件期间，60 ms 防抖）与 `stable`（松手后）是两套显式预算：

| | 初始区间 | 细化轮数 | 25/75% 探针 | 谱线代表数 | 目标间隔 |
|---|---|---|---|---|---|
| preview | 2 | 1 | 无 | 8 | 80 nm |
| stable | 8 | 6 | 有 | 32 | 12 nm |

- 每个区间用左/中/右（稳定模式再加两个探针）验证：所有空间光线是否落在同一块屏、
  未裁剪的交点区间是否完全落在接收窗内或外、采样间隔是否小于按色散率换算的接收窗宽。
  这样即使狭窄接收窗正好落在两个采样波长之间，也会被判为“未解析”，而不是默默漏掉。
- 探针只用于误差界定，功率恒为 0；能量按区间权重分配，权重和为 1。
- 结果携带 `sampling.energyUncertainty`（未解析能量，W）与
  `sampling.positionUncertainty`（位置误差，mm），面板直接展示。
- 密集谱线按能量加权代表波长合并（上限 8 / 32），合并保留总功率与光谱质心，
  并在 `mergedLines` 中报告，而不是静默略过。
